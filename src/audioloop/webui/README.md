# AudioLoop Web UI

Web-based interface for AudioLoop audio labeling tasks.

## Quick Start

```bash
# Activate audioloop and navigate to your project
source ~/tools/audioloop/.venv/bin/activate  # Or use your alias: al
cd ~/projects/my-classifier

# Start the web server
python -m audioloop.webui

# Open browser to http://127.0.0.1:5000
# Available candidate files will be auto-populated in the dropdown
```

## Testing with Existing Data

If you have existing candidates files, you can test immediately:

```bash
# 1. Start the web server (in one terminal)
python -m audioloop.webui

# 2. Open browser to http://127.0.0.1:5000

# 3. Load candidates file:
#    - Candidates CSV: outputs/labeling_candidates_v1.csv
#    - Dataset: fsd50k (or urbansound8k)
#    - Audio Directory: (leave empty for default)

# 4. Click "Load Candidates" and start labeling!
```

## Features

- **Visual Interface**: Clean, modern web UI replacing terminal commands
- **Audio Player**: HTML5 audio controls with auto-play
- **Keyboard Shortcuts**: 1/y (positive), 0/n (negative), space (play)
- **Progress Tracking**: Visual progress bar and completion status
- **Navigation**: Previous/next, jump to sample, find next unlabeled
- **Auto-save**: Labels saved automatically, manual save available

## Isolation

This web UI is completely isolated from core AudioLoop:

- **Reuses Logic**: Uses existing `SimpleAudioLabeler` class
- **Same Formats**: Reads/writes same CSV files as terminal tool
- **No Core Changes**: Zero modifications to AudioLoop workflow
- **Independent**: Can run separately from CLI tools

## Usage

1. **Load Candidates**: Select a candidates CSV from active learning
2. **Choose Dataset**: FSD50K or UrbanSound8K (or custom)
3. **Label Audio**: Click buttons or use keyboard shortcuts
4. **Navigate**: Use controls to move between samples
5. **Save**: Progress auto-saves, manual save available

Works with any candidates CSV generated by `python -m audioloop.active_learning`.

## Integration

Integrates seamlessly with existing AudioLoop workflow:

```bash
# Activate audioloop and go to your project
source ~/tools/audioloop/.venv/bin/activate  # Or: al
cd ~/projects/my-classifier

# Generate candidates
python -m audioloop.active_learning --class-name Drill --run-number 1

# Start web UI (auto-detects project and candidates)
python -m audioloop.webui
# Select candidate file from dropdown, label samples

# Merge labels back into training set
python -m audioloop.merge_labels training_sets/training_set_v1.csv outputs/labeling_candidates_v1.csv
```
